Place 3D model files here to enable real pieces.

Checkers (GLB/GLTF):
- models/checkers/man.glb
- models/checkers/king.glb

Chess (GLB/GLTF):
- models/chess/pawn.glb
- models/chess/rook.glb
- models/chess/knight.glb
- models/chess/bishop.glb
- models/chess/queen.glb
- models/chess/king.glb

Notes:
- Files must be accessible by the CRA dev server under /models/... paths.
- If files are missing, the app falls back to procedural pieces automatically.
- Recommended scale: roughly 1 unit per board square. Adjust model scale in your DCC if needed.
